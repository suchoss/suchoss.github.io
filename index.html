This application is not a public service and is not offered to anyone else. It is used solely by its owner to access their own Google account data for personal purposes. No one else can sign up for or use it.

Privacy Policy

Last updated: 22 October 2026

  • Who uses it: only the owner, with their own Google account.
  • What data is accessed: only the owner's own data in Google services, and only as needed to fulfil the owner's own requests.
  • Storage: access tokens are stored locally on the owner's own device. No data is stored on any server operated for this application.
  • Sharing: data is never sold, shared with, or transferred to third parties, and is not used for advertising.
  • Google API Services User Data Policy: use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: access can be revoked at any time at myaccount.google.com/permissions.
